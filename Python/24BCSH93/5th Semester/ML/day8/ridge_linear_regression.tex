    \hypertarget{evaluate-model-performance}{%
        \subsection{8. Evaluate model
        performance}\label{evaluate-model-performance}}

    We report several common regression metrics:

    \begin{itemize}
        \tightlist
        \item
        \textbf{RSS:} sum of squared prediction errors.
        \item
        \textbf{MSE:} average squared prediction error.
        \item
        \textbf{RMSE:} square root of MSE, in the same units as the target.
        \item
        \textbf{MAE:} average absolute prediction error.
        \item
        \textbf{R²:} proportion of test-target variation explained by the
        predictions, relative to predicting the test-target mean.
    \end{itemize}
